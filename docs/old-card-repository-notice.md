# Texte proposé pour le README de l’ancien dépôt

La carte T2C Clermont-Ferrand est désormais développée et distribuée avec
l’intégration dans [OUARZA/T2C-Clermont-Ferrand](https://github.com/OUARZA/T2C-Clermont-Ferrand).
Une seule installation HACS, catégorie Intégration, fournit les deux composants.
Le type `custom:t2c-clermontferrand-card` et les configurations existantes sont conservés.

Avant de désinstaller cette ancienne carte Dashboard, installer la version regroupée
et suivre le guide de migration du nouveau dépôt, puis vérifier l’affichage.
Les nouvelles modifications et signalements doivent être proposés dans le dépôt de l’intégration.

Ce texte est préparé pour publication après validation et disponibilité de la version
regroupée. L’ancien dépôt n’a été ni modifié, ni supprimé, ni archivé par ce travail.
